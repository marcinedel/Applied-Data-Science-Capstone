# Applied-Data-Science-Capstone
Końcowy projekt programu IBM Applied Data Science Capstone prezentujący pełny proces analizy danych: od pozyskiwania i przygotowania danych, przez EDA i wizualizacje, po budowę modeli uczenia maszynowego. Projekt koncentruje się na przekształcaniu danych w praktyczne wnioski wspierające decyzje biznesowe.
